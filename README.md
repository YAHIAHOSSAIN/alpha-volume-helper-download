## 🧩 ইনস্টল (Chrome)
1. zip নামিয়ে Extract করো (একটা `alpha-volume-helper` ফোল্ডার হবে)।
2. Chrome-এ খোলো `chrome://extensions` → উপরে ডানে **Developer mode** চালু করো।
3. **Load unpacked** → ওই `alpha-volume-helper` ফোল্ডার বাছো।
4. Binance Alpha-র টোকেনের পাতা খোলো — প্যানেল দেখাবে।

## 🔄 আপডেট
1. নতুন zip নামিয়ে আগের ফোল্ডারের জায়গায় Extract করো (একই ফোল্ডারে বদলে দাও)।
2. `chrome://extensions` → এক্সটেনশনের কার্ডে **🔄 (Reload)** চাপো → Binance পাতা রিলোড।
   সেটিংস আর হিসাব থেকে যায়।
